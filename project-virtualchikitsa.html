Virtual Chikitsa: Telemedicine Platform

A comprehensive web healthcare portal streamlining patient doctor appointments, remote video consultation sessions, and automated digital prescription management.

Project Domain Telehealth & HealthTech Systems
My Role Full-Stack Web Developer
Core Tech PHP, MySQL, JavaScript, HTML5, CSS3
Architecture Role-Based Access Control (Patient / Doctor / Admin)
Code Repository GitHub Repository ↗

1. Problem Statement & Healthcare Context

Access to qualified medical professionals remains a persistent bottleneck for patients in non-urban and semi-urban communities. Long travel times, overcrowded clinics, and physical document management add substantial friction to routine checkups and follow-ups.

Core Objective: Build a responsive, highly accessible telehealth platform enabling patients to browse verified medical practitioners, schedule consultations, attend remote sessions, and retrieve verifiable digital prescriptions.

Role-Based Workflows:

  • Patient Workflow: Account registration, doctor directory search filtered by specialization, real-time appointment booking slot picker, and past medical history view.
  • Doctor Portal: Schedule and availability manager, incoming appointment confirmation/reschedule dashboard, live consultation link activation, and digital prescription creation.
  • Administrative Controls: Verification of doctor credentials, system user auditing, and appointment log inspection.
  • Consultation Suite: Integrated video consultation interface paired with a collaborative notes canvas for physicians.

3. System Architecture & Database Design

1
Client Tier: Responsive UI built with clean semantic HTML, modular CSS, and JavaScript for async form validation and appointment slot updates.
2
Application Logic: PHP backend handling session security, parameterized SQL queries, password hashing, and appointment scheduling rules.
3
Data Persistence: Normalized MySQL schema linking Patients, Doctors, Specialties, Appointments, and Prescriptions with foreign key constraints.

Security & Data Integrity:

  • SQL Injection Prevention: Use of prepared statements via PHP PDO/MySQLi across all authentication and query endpoints.
  • Access Control: Session-level authentication checks preventing unauthorized privilege escalation across patient and doctor views.
  • Data Protection: Password hashing using strong cryptographic algorithms (bcrypt).

4. Technical Challenges & Lessons Learned

  • Appointment Slot Concurrency: Handling edge cases where two patients attempt to book the identical doctor time slot simultaneously; solved via transactional validation.
  • Cross-Device Usability: Ensuring the appointment scheduling grid and prescription viewing modals work smoothly across low-end mobile devices.
  • Prescription Formatting: Standardizing the digital prescription template so doctors can quickly enter medicine dosages, frequencies, and advice without layout issues.

Future Improvements

  • Integration of live payment gateways (e.g. Razorpay sandbox) for automated consultation billing.
  • Direct PDF rendering of prescriptions with cryptographic QR code validation.
  • AI-assisted symptom checker triage to recommend initial medical specializations.
